# Daily Task Management

An Android application built with Kotlin for organizing daily tasks.

## Features

- Register and log in with a locally stored, salted password hash.
- Add tasks with a name, description, and optional due date.
- Search tasks by name.
- View task details, edit saved tasks, and delete tasks.
- Mark tasks as completed or not completed.
- Save tasks locally so they remain available after the app is closed.
- Schedule a reminder for an incomplete task with a future due date.

## Technology

- Kotlin
- Android SDK
- AndroidX AppCompat
- RecyclerView
- SharedPreferences and JSON task storage
- Android AlarmManager notifications

## Build

Open this project in Android Studio and allow Gradle to sync. The project uses the Gradle wrapper included in the repository.

## Package

`com.example.dailytaskmanager`
